## 🚀 Featured Projects

### 1. CareerForge AI — AI-Powered Career Platform

**Connects job discovery, resume-based matching, and personalized AI guidance in one platform.**

- **Explainable job matching:** Combines weighted scoring with semantic similarity so matches go beyond keyword search
- **Resume retrieval:** FastEmbed and FAISS for finding relevant resume content
- **AI career mentor:** Grounded mentoring workflow built with LangGraph
- **Microservice architecture:** Next.js, Express, and FastAPI services backed by PostgreSQL, Redis, and Kafka
- **Background workers:** Resume processing, AI tasks, and notifications run off the request path

**Tech:** Next.js, TypeScript, Node.js, Python, FastAPI, PostgreSQL, Prisma, Redis, Kafka, LangGraph, FAISS, Docker

**Tech:** Next.js, TypeScript, Express.js, MongoDB, Firebase Auth, Gemini API
